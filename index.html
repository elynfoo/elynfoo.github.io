Terraform + Ansible Workflow

1. Terraform Reads main.tf → provisions Azure VM (Resource Group, VNet, NSG, Public IP, NIC, VM) ↓ 2. Ansible SSHs into VM using private key Installs Python, pip, Flask Creates app.py + systemd service Starts & enables Flask on boot ↓ 3. Flask App (on VM) Runs at http://<VM-IP>:5000 Returns: Hello from Ansible + Terraform! ↓ 4. Live Demo (containerized) Same app → Dockerfile → Docker Hub Deployed to AKS → http://40.90.189.161:5001

Web Network Scanner Workflow

1. Cron Job (every 5 minutes) */5 * * * * /usr/local/bin/network_scan.sh Triggers the scan script automatically ↓ 2. network_scan.sh (Bash) Checks lock file → prevents overlapping runs Runs: nmap -sV --open <network-range> Writes results to /var/www/scans/output.txt ↓ 3. Apache2 + PHP Browser requests http://<ip>/network.php .htaccess enforces basic auth login PHP reads output.txt safely (outside web root) htmlspecialchars() prevents XSS ↓ 4. Browser Dashboard Displays live hosts, open ports, services Auto-refreshes every 60 seconds File permissions: 775 (no chmod 777)
